MISSION FINANCE 2031 — OFFLINE-FIRST WEB APP

HOW TO INSTALL ON iPAD / iPHONE
1. Extract the ZIP.
2. Upload ALL the files inside the mission_finance_2031 folder to the root of a GitHub repository.
   Make the repository public ONLY if you are comfortable with the app source being public.
   Your financial data is not contained in the uploaded code and should NOT be committed.
3. In repository Settings > Pages, choose Deploy from a branch > main > /(root).
4. Open the provided HTTPS GitHub Pages website in Safari while online.
5. In Safari, Share > Add to Home Screen > Add. Launch the icon once online.
6. Subsequent launches can work offline after the service worker caches the app files.

NOTES
- Daily use, data entry, advisor, and PDF reports work without internet after installation.
- All transactions and goal balances are saved to local browser storage, not synced between devices.
- Download JSON backups regularly. Do NOT put personal backup JSON files in a public repo.
- The app starts with a 600 EUR opening bank balance and 395 EUR rent template for demonstration based on your screenshots. It DOES NOT import your old transaction history. Edit opening balances under Settings and enter/import your real records.
- A 992 EUR monthly spending limit is included as a placeholder based on your stated budget. It is not assumed to be received income.
- PDF reports are saved directly on device. Open the Reports tab and tap Download PDF.
- The financial advisor is rule-based and offline, not a live AI or regulated financial adviser.
- To update the app, upload the new source files. If the install still shows the older layout, reopen/refresh the Safari website while online to update its cache.
